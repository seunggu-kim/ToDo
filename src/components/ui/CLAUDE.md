# ui

## Purpose
Base UI components based on shadcn/ui. These are foundational components built on Radix UI primitives with Tailwind CSS styling. Used as building blocks throughout the application.

## Key Files

| File | Description |
|------|-------------|
| `avatar.tsx` | User avatar with image and fallback |
| `badge.tsx` | Label/tag badge with variants |
| `button.tsx` | Button with variants (default, destructive, outline, secondary, ghost, link) and sizes |
| `card.tsx` | Card container with header, content, footer sections |
| `checkbox.tsx` | Checkbox input with Radix UI |
| `dialog.tsx` | Modal dialog with Radix UI |
| `form.tsx` | Form components with react-hook-form integration |
| `input.tsx` | Text input field |
| `label.tsx` | Form label |
| `progress.tsx` | Progress bar indicator |
| `separator.tsx` | Horizontal/vertical separator line |
| `sonner.tsx` | Toast notification wrapper (uses sonner) |
| `textarea.tsx` | Multi-line text input |

## For AI Agents

### Working In This Directory
- These are generated by shadcn/ui CLI, but can be customized
- Use `cn()` utility for conditional class merging
- Components use `class-variance-authority` for variant management
- Radix UI provides accessibility out of the box

### Adding New Components
```bash
npx shadcn@latest add <component-name>
```

### Customization
- Modify variant styles in the component file
- Add new variants to the `cva()` configuration
- Global theme variables in `globals.css`

### Usage Pattern
```typescript
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"

<Button variant="outline" size="sm">Click</Button>
<Input placeholder="Enter text" />
```

## Dependencies

### External
- `@radix-ui/react-*` - Primitive components
- `class-variance-authority` - Variant management
- `clsx`, `tailwind-merge` - Class utilities
- `sonner` - Toast notifications
- `lucide-react` - Icons
